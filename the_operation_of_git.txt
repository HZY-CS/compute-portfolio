🔄 Git 日常维护更新（4步循环）
Git 就像游戏存档。第一次通关（init + 首次 commit + push）已经完成了。以后的每一天，都是在现有存档上打补丁。

第1步：查看状态（看看改了啥）
git status
作用：Git 会告诉你哪些文件被修改了。被修改的文件会显示红色。

第2步：添加与提交（打包存档）
git add .(这是全体更新 可以改为特定的文件)
git commit -m "update: 完善模板测试与友元函数"
作用：git add . 把所有红色文件放进暂存区（变绿）；git commit 把它们打包成一个新的存档，并在本地记录备注。

第3步：推送到云端（同步到GitHub）
git push
作用：因为你昨天配置了 -u origin main，现在只需要敲一句 git push，本地的最新存档就会自动同步到 GitHub 网页上。

第4步：检查成果（可选）
git log --oneline
作用：按行显示你所有的存档记录（哈希值 + 备注），极其清爽。
